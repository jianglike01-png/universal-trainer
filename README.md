# 通用训练器 Universal Trainer

先验预测 → 隔离反馈 → 贝叶斯对账 → 偏差报告。个人判断力校准工具，单人自用，数据只存在手机本地。

PWA：iPhone 用 Safari 打开 → 分享 → 添加到主屏幕，之后就是一个独立 App，离线可用。

## 使用循环

1. **建样本**：一个要猜的事（视频点赞量 / 简历是否录取 / 任务几天做完 / 事件走向）
2. **下注**：填预测值 + 置信度 + 一句理由，提交即写进哈希链，只读，没有任何修改入口
3. **揭晓**：到时限录入真实结果
4. **对账**：自动算 Brier，进校准曲线和偏差报告

## 记分口径

| 类型 | 命中判定 | 误差 |
|---|---|---|
| 二元 | 选择方向与实际一致 | Brier = (P(是) − 实际0/1)² |
| 多选 | 选中项正确 | 多分类 Brier：c 给选中项，剩余 (1−c) 在其余选项均摊 |
| 数值 | 落在 预测 ×(1±容差) 内 | 对数相对误差 \|ln(预测/实际)\| |
| 时间 | 同上（单位：天） | 同上 |

**统一口径**：每种类型都产出一个 Brier 分（供校准曲线用），数值/时间额外产出对数误差（供"平均高估 N%"）。

- 校准曲线：横轴声称把握（50–59/60–69/70–79/80–89/90–99 五档），纵轴实际命中率，虚线是完美校准
- 逾期录入：`overdue=true`，权重降到 0.3，默认不进核心曲线（可在「我的」里打开）
- 可疑标记：连续 ≥6 条 90% 以上且全部命中，权重再 ×0.5
- 防伪：每条预测/结果 `hash = SHA256(prev_hash | seq | 稳定序列化记录)`，「我的」页可自检断链

## 开发

```bash
npm install
npm run dev       # http://localhost:5173/universal-trainer/
npm test          # 27 项纯函数单测：记分/校准/哈希链
npm run build     # 产出 dist/
```

技术栈：Vue 3 + Vite + Dexie(IndexedDB) + 手写 SVG 图表 + vite-plugin-pwa。

相对原提纲的调整（提纲允许微调）：Pinia → 轻量 store（状态量小）、Vant → 原生控件（体积小、iOS 手感好）、ECharts → 手写 SVG（点少，静态更清晰，少 1MB 依赖）。
